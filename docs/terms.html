Умови використання Rieltor

Умови користування вебзастосунком Rieltor та автоматичною публікацією оголошень у TikTok і Threads.

Оновлено: 3 вересня 2026 року.

Про сайт та сервіс

Rieltor — вебзастосунок персонального рієлтора Ірини Ліннік, доступний на rieltor.dpdns.org. Він містить інформацію про об’єкти нерухомості та контактну форму для звернень. Застосунок Rieltor автоматично публікує фото об’єктів нерухомості та короткий опис у TikTok і Threads, підключені власником сайту.

Контактна форма

Заповнюючи форму на сайті, ви погоджуєтесь на передачу вказаних даних (ім’я, телефон, адреса об’єкта, опис запиту) рієлтору через Telegram Bot API з метою зворотного зв’язку. Використання цих даних описано в Політиці конфіденційності.

Використання TikTok-акаунту

Підключаючи TikTok-акаунт до застосунку Rieltor через TikTok Login Kit, власник акаунту надає дозвіл на:

  • доступ до базової інформації акаунту;
  • публікацію фотопостів (фото об’єктів нерухомості та короткого опису) від імені акаунту через TikTok Content Posting API (Direct Post).

Публікується лише контент, підготовлений через внутрішній процес підготовки оголошень власника сайту. Сервіс не публікує будь-який інший контент від імені підключеного акаунту.

Використання Threads-акаунту

Підключаючи Threads-акаунт, власник надає дозволи threads_basic і threads_content_publish для публікації підготовлених дописів та фотокаруселей. Інтеграція Threads працює незалежно від TikTok.

Належність акаунту

Сервіс призначений для підключення робочих TikTok- і Threads-акаунтів, якими керує власник сайту, і не призначений для масової реєстрації сторонніх користувачів.

Відповідальність за контент

Весь контент, що публікується (фото, опис, ціна об’єкта), формується власником сайту. Власник сайту несе відповідальність за точність і законність опублікованої інформації.

Доступність сервісу

Ми не гарантуємо безперервну роботу сайту чи сервісу публікації. Публікація може затримуватись або не відбутися через обмеження TikTok або Threads API, технічне обслуговування чи інші причини поза нашим контролем.

Припинення доступу

Власник акаунту може відключити TikTok або Threads-акаунт від сервісу в будь-який момент через налаштування відповідної платформи або звернувшись за контактом нижче.

Зовнішні сервіси

Сайт містить посилання на Telegram, TikTok, Threads та DIM.RIA. Користування цими сервісами регулюється їхніми власними умовами використання та політиками конфіденційності.

Зміни до цих умов

Ці умови можуть оновлюватися. Продовження використання сайту чи сервісу після внесення змін означає згоду з оновленими умовами.
