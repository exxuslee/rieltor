Політика конфіденційності

Як використовуються дані для зворотного зв’язку та підключених TikTok- і Threads-акаунтів.

Оновлено: 4 серпня 2026 року.

Які дані можуть бути надані

Через форми сайту ви можете вказати ім’я, номер телефону, адресу об’єкта та короткий опис запиту.

Мета використання

Контактні дані потрібні виключно для відповіді на звернення, уточнення запиту, організації консультації або перегляду нерухомості.

Як надсилаються заявки

Дані з форм надсилаються рієлтору безпосередньо через Telegram Bot API. Сайт не зберігає окрему базу заявок.

Підключення TikTok-акаунту

Сайт та пов’язаний із ним сервіс автопублікації використовують TikTok Login Kit для авторизації робочого TikTok-акаунту рієлтора. При підключенні ми отримуємо базову інформацію про акаунт (ім’я користувача, ідентифікатор акаунту) в межах дозволу user.info.basic, а також токени доступу (access token і refresh token), необхідні для публікації контенту через TikTok Content Posting API.

Як використовуються дані TikTok-акаунту

Отримані токени використовуються виключно для:

  • підтвердження підключення TikTok-акаунту;
  • автоматичної публікації фотопостів (фото об’єктів нерухомості та короткого опису) від імені підключеного акаунту через функцію Direct Post;
  • оновлення токена доступу для підтримки з’єднання.

Ці дані не використовуються для реклами, профілювання чи будь-яких інших цілей, не пов’язаних із публікацією контенту підключеного акаунту.

Підключення Threads-акаунту

Для незалежної публікації у Threads сервіс використовує офіційний Threads API з дозволами threads_basic і threads_content_publish. Зберігаються ідентифікатор акаунту та довгоживучий access token, потрібні лише для публікації підготовлених дописів і каруселей та оновлення доступу.

Зберігання та безпека

Токени доступу зберігаються на наших серверах у захищеному вигляді та не передаються третім особам. Вони використовуються лише для авторизованих запитів до TikTok і Threads API від імені підключених акаунтів. Токени зберігаються, поки акаунт залишається підключеним до сервісу.

Видалення даних

Ви можете в будь-який момент відключити TikTok або Threads-акаунт від сервісу через налаштування відповідної платформи або звернувшись за контактом нижче. Після відключення збережені токени видаляються з наших систем.

Зовнішні сервіси

Надсилання форм обробляється Telegram відповідно до правил конфіденційності цього сервісу. Публікація контенту обробляється TikTok або Threads відповідно до правил відповідної платформи. Переходячи за посиланнями на Telegram, TikTok, Threads або DIM.RIA, ви також користуєтеся відповідним зовнішнім сервісом і його правилами конфіденційності.
