# SEO: действия после публикации

Код сайта уже использует HTTPS URL, canonical, sitemap и структурированные данные. Следующие шаги требуют доступа владельца к внешним сервисам.

## GitHub Pages и домен

1. В настройках GitHub Pages включить **Enforce HTTPS**.
2. Проверить, что `http://rieltor.dpdns.org/` перенаправляет на `https://rieltor.dpdns.org/` кодом 301/308.
3. При покупке брендового домена сначала обновить домен в HTML, генераторе, `CNAME`, `robots.txt` и sitemap, затем настроить постоянные перенаправления со старых URL.

## Google Search Console

1. Добавить и подтвердить доменный ресурс `rieltor.dpdns.org`.
2. Отправить `https://rieltor.dpdns.org/sitemap.xml`.
3. Проверить главную, `buy.html` и 2–3 страницы из `/properties/` через URL Inspection.
4. В отрендерованном HTML проверить `h1`, описание объекта, canonical и JSON-LD.
5. Запросить индексирование ключевых URL и затем контролировать отчёты Pages, Performance и Core Web Vitals.

## Google Business Profile

1. Создать или подтвердить профиль Ирины Ліннік.
2. Использовать одинаковые имя, телефон, часы работы и регион обслуживания на сайте, DIM.RIA и в профиле Google.
3. Добавить ссылку на сайт, портрет и реальные фотографии объектов.
4. Регулярно отвечать на отзывы; не переносить отзывы на сайт без разрешения автора.

## Контент и данные

1. До продвижения заменить демонстрационные данные и иллюстрации на подтверждённые объекты и собственные фотографии.
2. Добавить подтверждённые опыт, квалификацию, кейсы и отзывы на страницу «Про Ірину».
3. Подключить серверный обработчик форм и после этого актуализировать политику конфиденциальности.
4. Добавлять аналитику только вместе с корректным уведомлением о cookies/измерениях, если оно требуется выбранным инструментом и юрисдикцией.
